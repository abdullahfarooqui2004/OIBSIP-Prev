# 🍕 Pizza Co. — Backend API & WebSockets Server

Modular REST API and WebSockets server built with **Node.js (ESM)**, **Express.js**, **MongoDB / Mongoose**, **Socket.io**, and **Razorpay**.

For complete project documentation, environment setup, and architecture details, refer to the root [README.md](../README.md).

---

## 🛠️ Development & Script Reference

```bash
# Install dependencies
npm install

# Start development server with hot-reload (Nodemon)
npm run dev

# Start production server
npm start

# Seed initial inventory items (19 artisanal ingredients) and admin account
npm run seed
```
