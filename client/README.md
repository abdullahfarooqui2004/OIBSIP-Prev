# 🍕 Pizza Co. — Frontend Client

Single-page React application built with **React 19**, **Vite**, and **Tailwind CSS v4** featuring real-time WebSockets integration, Razorpay modal checkout, and customer order history.

For complete project documentation, environment setup, and architecture details, refer to the root [README.md](../README.md).

---

## 🛠️ Development & Build Scripts

```bash
# Install dependencies
npm install

# Start Vite local development server (with /api and /socket.io proxy to http://localhost:5000)
npm run dev

# Run ESLint syntax & style checks
npm run lint

# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
